# 📚 Algoritmos e Estruturas de Dados

Repositório desenvolvido durante a disciplina **Algoritmos e Estruturas de Dados** do curso de **Análise e Desenvolvimento de Sistemas da UniSenac**.

O objetivo deste repositório é reunir os exercícios e projetos desenvolvidos ao longo da disciplina, aplicando conceitos fundamentais de programação, estruturas de dados e algoritmos utilizando a linguagem **Python**.
